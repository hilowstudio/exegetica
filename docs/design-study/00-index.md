# Design study: what CMU HCII and RISD Graphic Design teach

This is a study set built on 2026-11-08 from:
- the CMU HCII course list (92 course pages)
- RISD Graphic Design's program pages and course search (39 distinct courses across Fall 2026, Wintersession 2027 and Spring 2027)

The course pages give subjects and descriptions. These notes fill in the content behind each subject, drawn from the field's standard texts and checked against reputable free sources where I could reach them.
