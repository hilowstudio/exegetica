# Cover prompts: Sports & Recreation

25 books, two editions each, from the template in [../cover-art-prompt.md](../cover-art-prompt.md) (Version B, with lettering).

- **Light edition:** parchment `#f0e8dc` cloth, rose `#c05a64` motif.
- **Dark edition:** ink `#1e2026` cloth, soft rose `#dd8089` motif.
- **Size:** 1600 × 2400 px, 2:3 portrait. If the model caps lower, use 1024 × 1536 or its nearest 2:3 option (Midjourney: `--ar 2:3`).
- **File names:** `{slug}-light.png` and `{slug}-dark.png`. The slug is the book's Reading Room ID.

Paste each block as-is. Use the same motif for both editions of a book. Generators still slip on lettering, so check the spelling of the title and author line before saving; regenerate rather than retouch.
