# Genre motifs: first draft for review

Twenty candidate motifs per Reading Room shelf, for the house cloth covers. Each is drawn once by the image model in the same style as the library-wide sprig (one flat silhouette, papercut detail, black on white). Code then recolors it and repeats it across the cover.

How these were chosen:

- **From the shelf's world, not its clip-art symbol.** The objects belong to the books themselves: their period, places and props. There are no rockets, magnifying glasses, comedy-and-tragedy masks or hearts.
- **Readable as a tiny silhouette.** Each motif is a single object with a distinctive outline, because it repeats about 100 times at roughly a tenth of the cover's width.
- **No people, faces, letters or numbers.** These don't repeat well and drift off style.
- **Christianity and World Religions.** These use objects from Scripture and devotional practice rather than bare symbols.

Strike, swap or add lines, then I'll generate.
