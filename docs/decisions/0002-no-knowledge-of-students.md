# 0002: The machine holds no knowledge of a student

Recorded 2026-11-02 from the harness Memory spike, under the position statement.

**Decision.** The model is never given knowledge of a particular student. Ruled out under any future decision: recall across chats, summaries or profiles of a student, facts extracted from a student's messages, embeddings of student text, the API memory tool, a student's name, class, or grade in any prompt, "welcome back" behavior, and analytics on a student's topics or moods. A student's own records (saved studies, memory verses, reading place, display settings) belong to the student and are never fed back to the model as knowledge about them.

**Why.** The position statement reserves being seen, known, and loved to God, parents, and teachers, and limits students to using AI as a reference work, which does not recall its reader. A system that remembers a student is the first step toward a companion.

**Enforced in.** By absence today: no code builds any of the above. The system prompt does not change with sign-in. A test that proves the prompt is identical signed in and signed out is planned (proposal, Layer 4).

**Reverse when.** Not reversible by an engineering decision; it would require changing the position statement.
